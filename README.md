# SKILL ISSUE

Learn it. Prove it. Or admit the skill issue.

A small learning app that teaches, checks that you really understood, and brings things back for review. English, Português, 中文. No account.

## Open it

**https://goodgamejon.github.io/life-rpg/**

- **Android:** open the link in Chrome, then ⋮ → **Install app** (or **Add to Home screen**).
- **iPhone / iPad:** open the link in Safari, then Share → **Add to Home Screen**.
- **Android file (APK):** https://goodgamejon.github.io/life-rpg/skill-issue.apk (needs Chrome installed)
- **Send it to a friend:** in the app, Settings → The app → Share. Or just send them the link above.

## Privacy

Everything you write stays on your own device. If you use voice input, your browser's own speech service hears it, not us.
